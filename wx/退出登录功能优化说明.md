# 退出登录功能优化说明

## 📋 更新日期
2026-03-09

## 🎯 更新目标
优化退出登录功能，确保退出时完全清空 token 和用户信息，并正确跳转到登录页面。

---

## ✅ 修改内容

### 1. 个人中心退出方法 (`pages/profile/profile.js`)

**修改前**（第 379-396 行）：
```javascript
logout() {
  wx.showModal({
    title: '确认退出',
    content: '确定要退出登录吗？',
    confirmColor: '#ff4757',
    success: (res) => {
      if (res.confirm) {
        // 清除本地存储的 token
        wx.removeStorageSync('token');
        // 清除 tabBar 徽标
        wx.removeTabBarBadge({ index: 3 });
        // 跳转到登录页
        wx.reLaunch({ url: '/pages/login/login' });
      }
    }
  });
}
```

**修改后**：
```javascript
logout() {
  wx.showModal({
    title: '确认退出',
    content: '确定要退出登录吗？',
    confirmColor: '#ff4757',
    success: (res) => {
      if (res.confirm) {
        // 调用 API 的 logout 方法清空 token 和用户信息
        api.user.logout()
          
        // 清除 tabBar 徽标
        wx.removeTabBarBadge({ index: 3 })
          
        // 跳转到登录页（使用 reLaunch 确保关闭所有页面）
        wx.reLaunch({
          url: '/pages/login/login'
        })
      }
    }
  })
}
```

**改进点**：
- ✅ 调用统一的 `api.user.logout()` 方法
- ✅ 确保 token 和用户信息都被清除
- ✅ 使用 `reLaunch` 关闭所有页面，防止返回

---

### 2. API 退出方法 (`api/user.js`)

**现有实现**（第 41-44 行）：
```javascript
function logout() {
  request.removeToken();
  wx.removeStorageSync('userInfo');
}
```

**功能说明**：
- ✅ 清除 token（通过 `request.removeToken()`）
- ✅ 清除用户信息缓存
- ✅ 无需额外修改

---

### 3. 应用级清除方法 (`app.js`)

**现有实现**（第 195-207 行）：
```javascript
clearLoginInfo() {
  this.globalData.userInfo = null
  this.globalData.token = null
  this.globalData.unreadCount = 0
  
  try {
    request.removeToken()
    wx.removeStorageSync('userInfo')
    wx.removeTabBarBadge({ index: 2 })
  } catch (error) {
    console.error('清除登录信息失败:', error)
  }
}
```

**功能说明**：
- ✅ 清除全局数据中的用户信息
- ✅ 清除全局数据中的 token
- ✅ 重置未读消息数为 0
- ✅ 清除本地存储的 token 和用户信息
- ✅ 清除 tabBar 徽章（索引 2）

## 🔍 关键改进

### 1. 统一清除逻辑
**改进前**：在 profile.js 中直接操作 storage
**改进后**：调用 `api.user.logout()` 统一处理

### 2. 完全页面关闭
**使用 `wx.reLaunch()`**：
- 关闭所有当前页面
- 只保留登录页
- 防止用户按返回键回到个人页

### 3. 双重保障
**两处清除机制**：
- `api.user.logout()` - API 层面的清除
- `app.clearLoginInfo()` - 应用层面的清除（用于 token 失效等场景）
